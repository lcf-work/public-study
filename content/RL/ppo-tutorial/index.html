互动式强化学习教程近端策略优化 PPO：从策略梯度到能跑的算法

PPO（Proximal Policy Optimization）是当今最常用的强化学习算法之一——从 OpenAI 的机器人到对大语言模型做 RLHF，背后多半是它。 但 PPO 不是凭空出现的，它是一连串「修补」的终点：每一步都在解决上一步留下的一个具体痛点。 这套教程带你沿着这条修补链一路走到底，每个关键想法都配一个能在网页里亲手把玩的实验，最后在浏览器里从零训练出一个会平衡杆子的智能体。

🧭 一句话路线图
策略梯度（直接优化策略，但方差大）→ 基线 / 优势 / Actor-Critic（压方差）→ 重要性采样（想重复利用数据，却带来分布失配）→ 信赖域 TRPO（限制步子别迈太大，但难算）→ PPO 裁剪（用一行 min-clip 优雅地近似信赖域）→ GAE + 完整算法（拼成能跑的工程）。 每一章解决前一章的一个遗留问题。
第 1 章

策略梯度：直接对策略做梯度上升

为什么不学价值、直接学策略？得分函数（log 导数）技巧、策略梯度定理与 REINFORCE。亲手看「好动作被点赞」。
第 2 章

与方差搏斗：基线、优势与 Actor-Critic

REINFORCE 的诅咒是方差。基线为何能在不引入偏差的前提下压低方差；优势函数「比平均好多少」；评论员登场。
第 3 章

同策略之困：重要性采样与信赖域

数据用一次就扔太浪费 → 重要性采样想重复利用 → 但两个策略一远，方差爆炸、目标失真 → 信赖域 TRPO 限制步长。
第 4 章

PPO 的神来之笔：裁剪式目标函数

本教程的核心。一行 min-clip 如何「软性」实现信赖域。亲手拆解那张经典的裁剪目标图，看梯度在何处被「掐断」。
第 5 章

完整的 PPO：GAE 与亲手训练 CartPole

GAE 的偏差-方差旋钮 λ；完整损失（裁剪+价值+熵）；然后在浏览器里实时训练，并对比「关掉裁剪」的崩溃。

使用方法

网页部分

纯静态页面，零外部依赖（连画神经网络训练都是手写的 JS）。直接用浏览器打开即可，或起一个本地服务：

xdg-open ~/studyspace/RL/ppo-tutorial/index.html
# 或
cd ~/studyspace/RL/ppo-tutorial && python3 -m http.server 8000   # 访问 http://localhost:8000

每个紫青色面板都是互动实验，先动手玩，再往下读。第 5 章的训练动画建议在性能尚可的机器上看。

编程实践部分

实践脚本在 practice/，纯 numpy 从零实现（不依赖 PyTorch / Gym），与网页里的 JS 引擎算法一致：

cd ~/studyspace/RL/ppo-tutorial/practice
python3 01_reinforce.py       # 第1–2章：REINFORCE（可开关基线）
python3 02_actor_critic.py    # 第2章：优势 Actor-Critic
python3 03_ppo.py             # 第4–5章：完整 PPO（裁剪 + GAE）

每个脚本顶部都有「实验区」常量，正文实践环节会提示你改哪些、看什么。

需要的前置知识

会有帮助但并非必需：状态/动作/奖励/回报、折扣因子 γ、状态价值 V(s) 与动作价值 Q(s,a) 的概念、以及「梯度下降/上升」的基本直觉。 如果你做过本目录下的蒙特卡洛互动教程，那些「采样求期望」「优势/基线」的直觉会在这里反复用到。
