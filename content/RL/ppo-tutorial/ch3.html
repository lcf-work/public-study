第 3 章同策略之困：重要性采样与信赖域

策略梯度是同策略（on-policy）的：参数一更新，旧策略采的数据就「过期」了，只能重采。 样本这么贵，我们想一批数据反复用几次。这一念之差，引出重要性采样、它的方差陷阱，以及 TRPO 的信赖域——PPO 的直接前身。

3.1同策略的浪费

策略梯度 ∇J = 𝔼τ~πθ[…] 里的期望是对当前策略 πθ 采样求的。 一旦做完一次梯度上升，θ 变了，πθ 也变了，之前那批轨迹是用旧策略采的，不再服从新分布，理论上就不能再用。 于是流程是：采一大批 → 更新一次 → 全部扔掉 → 再采。Easy RL 里说得很直白：策略梯度大部分时间都耗在采样上。

能不能用旧策略 πold 采一次数据，让新策略 πθ 在这批数据上更新很多次？ 这要求我们「用一个分布的样本，去估计另一个分布下的期望」。这正是重要性采样。

3.2重要性采样：用 q 的样本估 p 的期望

恒等式只是把概率密度的比值乘进去：

𝔼x~p[f(x)] = 𝔼x~q[ (p(x)/q(x))·f(x) ](3.1)

那个比值 p(x)/q(x) 叫重要性权重，用来「修正」两个分布的差异。理论上 q 可以是任何分布（只要 p>0 处 q>0）。 但理论归理论——它有个隐藏的大坑：期望虽然不变，方差却可能爆炸。当 p 和 q 离得远，少数落在「p 大、q 小」区域的样本会被乘上巨大的权重， 采样次数不够时，估计值会疯狂跳动甚至系统性偏错。先把这个坑看清楚。

互动 3-A重要性采样的方差陷阱

目标：用提议分布 q（橙）的样本估计目标分布 p（青）下的期望 𝔼p[f]，f(x)=x（真值见红线）。 上图是两个分布与权重曲线 w(x)=p/q；下图是重复 800 次、每次 N 个样本得到的估计值分布。拖动 q 的偏移，看两分布拉开后估计如何失控。

观察：① 偏移=0（p=q）时估计又准又稳；② 偏移加大，下图直方图越摊越宽，有效样本数 ESS 暴跌—— 这意味着名义上 N 个样本，实际只相当于寥寥几个有用；③ 偏移很大且 N 小时，估计经常系统性偏离真值（极端权重的样本难得被采到）。 结论：重要性采样只有在两个分布「足够接近」时才靠谱。

3.3把策略梯度改成「可复用数据」的形式

用重要性采样把策略梯度的目标改写成「用旧策略采样、优化新策略」的代理目标（surrogate objective）：

LIS(θ) = 𝔼(s,a)~πold[ (πθ(a|s) / πold(a|s)) · A(s,a) ](3.2)

记概率比 r(θ) = πθ(a|s)/πold(a|s)。在 θ=θold 处 r=1，且可以验证 ∇θLIS 在该点正好等于原始策略梯度。 好处是：数据从 πold 采一次，就能让 πθ 反复做几步梯度上升——样本效率大涨。

⚠ 但 3-A 的坑还在
代理目标 LIS 只在 πθ 与 πold 足够接近时才可信。一旦 πθ 在这批旧数据上「优化过头」、跑得离 πold 太远， 重要性权重方差爆炸、代理目标与真实表现严重脱节——你以为在爬坡，其实早已冲下悬崖。

3.4悬崖与信赖域

为什么「优化过头」会掉下悬崖？因为代理目标 L(θ) 只是真实目标 J(θ) 在 θold 附近的一阶近似： 方向（梯度）在出发点是对的，但你沿这个方向走得越远，近似误差越大（背后是策略变了、智能体访问的状态分布也跟着变，而代理目标却仍按旧分布算账）。 TRPO 的理论给出：这个误差可以被新旧策略的 KL 散度约束住。于是自然的对策是——只在一个「可信的邻域」内最大化代理目标，这就是信赖域（trust region）。

TRPO：  maxθ L(θ)  s.t.  𝔼s[ KL( πold(·|s) ‖ πθ(·|s) ) ] ≤ δ(3.3)

下面这个图把「代理目标、真实目标、信赖域、悬崖」放在一起。它采用 TRPO 的经典视角：真实目标局部是个有顶的山包，代理目标是出发点处的切线（只会一路向上「画饼」），KL 随步长二次增长。

互动 3-B代理目标的「画饼」与信赖域的刹车 （TRPO 一阶视角，示意）

横轴是「从 θold（=0）迈出的步长」。青线 = 真实目标 J(θ)（有个真实的峰，过了就下坡）； 橙虚线 = 代理目标 L(θ)（一阶近似，只会一路上扬地「画饼」）。阴影是信赖域 |步长| ≤ √(2δ)。

拖动 δ：① δ 很小 → 在信赖域边界取到的 θ 稳稳落在峰的左侧，真实表现确实提升（安全的小步）； ② δ 调大 → 边界越过真实峰值，按代理目标「该继续上」，但真实目标已经开始下跌——这就是掉下悬崖； ③ 代理目标永远在画饼（橙线只升不降），正是它骗你迈出致命大步。信赖域的唯一职责就是踩刹车。

两点要厘清：(1) KL 度量的是「行为距离」不是「参数距离」——我们在乎的是两个策略在相同状态下输出的动作分布有多不同，而非网络权重数值差多少（参数微动可能让动作大变，反之亦然）。 (2) PPO 其实仍是同策略算法：这里的「旧策略」只是上一轮迭代的自己，数据复用也只持续几个 epoch，πold 与 πθ 始终被刻意按在很近的地方。

💡 TRPO 很对，但很重
TRPO 把 KL 当成硬约束，要解一个带约束的优化（共轭梯度、线搜索、二阶信息……），实现复杂、计算昂贵。 有没有办法不解约束优化、只用普通的 SGD/Adam，就达到「步子别迈太大」的效果？ PPO 给出的答案简单得令人发笑——下一章见。

3.5本章小结

  • 策略梯度是同策略的，数据用一次就废，采样昂贵。
  • 重要性采样让我们用旧策略的数据优化新策略（代理目标 LIS，概率比 r(θ)），但当两策略相距太远时方差爆炸、目标失真。
  • 代理目标只是真实目标的局部一阶近似；走太远会「掉下悬崖」。误差由 KL 散度约束。
  • TRPO：在「KL ≤ δ」的信赖域内最大化代理目标。正确但实现笨重。
🤔 承上启下
