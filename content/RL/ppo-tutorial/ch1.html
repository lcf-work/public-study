第 1 章策略梯度：直接对策略做梯度上升

价值方法（如 Q-learning）的思路是「先学会评估，再据此选动作」。策略梯度反其道而行： 把策略本身当成一个带参数的函数，直接对「期望回报」做梯度上升。这是通往 PPO 的第一块基石。

1.1为什么直接学策略？

基于价值的方法要先估出 Q(s,a)，再用 argmax 选动作。这在很多场景下别扭：

  • 连续动作：动作是方向盘转角这样的实数，argmax 要在无穷多动作里搜索，很麻烦。直接输出一个动作（分布）则自然得多。
  • 需要随机策略：石头剪刀布的最优策略是「各 1/3」。确定性的 argmax 策略学不出这种刻意的随机；而带参数的概率策略可以。
  • 直接优化目标：我们真正想要的是「回报高」，那就直接拿回报当目标函数去优化策略，不绕价值这个中间商。

我们把策略写成 πθ(a|s)——一个参数为 θ 的网络，输入状态 s，输出动作的概率分布。两种常见形式：

  • 离散动作：网络输出每个动作的「分数」（logits），过一个 softmax 变成概率。
  • 连续动作：网络输出一个高斯分布的均值 μθ(s)（方差可固定或也学），动作从 N(μθ(s), σ²) 采样。

目标函数就是期望回报（演员每局得分的平均）：

J(θ) = 𝔼τ~πθ[ R(τ) ]，  其中轨迹 τ = (s₀,a₀,r₁,s₁,…)(1.1)

我们要的是 ∇θ J(θ)，然后 梯度上升 θ ← θ + α∇θJ。问题是：回报 R(τ) 由环境产生、根本不可微，怎么对 θ 求梯度？

1.2得分函数技巧：把梯度「搬」到 log 上

这里有一个漂亮的恒等式，是整个策略梯度的引擎。对任意以 θ 为参数的分布 pθ(x) 和任意函数 f(x)：

∂ 得分函数（log 导数）技巧
∇θ 𝔼x~pθ[f(x)] = 𝔼x~pθ[ f(x) · ∇θ log pθ(x) ](1.2)
推导只用一行：∇𝔼[f] = ∇∫p·f = ∫(∇p)·f = ∫p·(∇p/p)·f = ∫p·(∇log p)·f = 𝔼[f·∇log p]。 关键一步是 ∇p = p·∇log p。注意 f 完全不需要可微——它只是个权重。

把它用到 J(θ) 上（R(τ) 当作 f，轨迹概率当作 pθ），并利用「轨迹概率里只有策略那部分含 θ，环境转移不含 θ」，就得到策略梯度定理：

∇θ J(θ) = 𝔼τ[ ( Σt ∇θ log πθ(at|st) ) · R(τ) ](1.3)

读懂它：梯度方向 = 各步「让所选动作概率更大」的方向（∇log π），再用整条轨迹的回报 R(τ) 加权。 回报为正的轨迹，其上所有动作的概率被推高；回报为负的，被压低。这就是「好动作点赞、坏动作点踩」。 环境的不可微，被这一招完全绕开了——我们只对自己能控制的策略求导。

互动 1-A好动作被点赞：softmax 策略的 REINFORCE

一个最简单的单步问题：4 个动作，各有未知的真实平均奖励（柱内灰条）。策略是 4 个 logits 过 softmax，初始均匀。 每一步：按当前概率采样一个动作 a，得到带噪奖励 r，按 θj ← θj + α·r·(𝟙[j=a] − πj) 更新（这正是式 (1.3) 的单样本估计）。

紫线：最优动作（绿色高亮）的概率；它应当涨向 1。

试一试：① 直接连点「+500」，看最优动作概率爬升、平均奖励上升——梯度确实在「点赞」好动作； ② 勾选「整体 +5」后重置再训练：所有奖励都变成大正数，学习明显更慢更抖——因为此时连「不好的动作」也因为奖励是正的而被点赞，全靠 softmax 归一化才勉强分出高下。 这个毛病正是第 2 章「基线」要根治的。

1.3REINFORCE 与「奖励分配」

把式 (1.3) 变成算法就是 REINFORCE（蒙特卡洛策略梯度）：跑完整回合 → 算回报 → 按式 (1.3) 更新 → 再跑。两个立刻能上的改进：

  1. 奖励-to-go（reward-to-go）：用「该动作之后的回报」Gt=Σt′≥t γt′−trt′ 给每个动作打分，而不是整条轨迹的总分。 道理很简单：动作 at 影响不了它之前发生的奖励，那些分不该算在它头上。这样每个动作拿到更「公平」的分数，方差也更小。
  2. 折扣 γ：越远的奖励，和当前动作的因果关系越弱，乘 γk 打折。
∇θ J ≈ 𝔼[ Σt ∇θ log πθ(at|st) · Gt ](1.4)

对连续动作的高斯策略，得分函数有个干净的形式 ∇μ log π = (a − μ)/σ²：更新方向就是「朝着刚采样到的动作偏移」，再乘上回报。回报为正就朝它靠拢，为负就远离。下面这个「学习瞄准」的实验把这一点画了出来。

互动 1-B学习瞄准：连续动作的策略梯度

动作是平面上的一个点，从高斯分布 N(μ, σ²I) 采样（μ 是要学的「准星」蓝点，σ 是探索范围）。 奖励 = −(到红星的距离)。每步采样一个动作（橙点），按 μ ← μ + α·R·(a−μ)/σ² 更新。看准星如何一步步挪向靶心。

|

试一试：① σ 调大 → 橙点撒得更开（探索多），准星挪动更快但更抖；σ 调小 → 稳但慢，且初始离靶远时几乎学不动（采样根本碰不到靶）。 ② 这就是探索与利用在连续动作里的体现；σ 也可以交给网络去学。③ 注意更新方向永远是「朝着拿到正奖励的样本」——得分函数 (a−μ)/σ² 的几何意义。

⌨ 编程实践 ①从零写 REINFORCE 跑 CartPole

实践脚本用纯 numpy 实现了一个小神经网络策略，在经典的 CartPole（平衡杆）上跑 REINFORCE：

cd ~/studyspace/RL/ppo-tutorial/practice
python3 01_reinforce.py

它会打印每若干回合的平均回合长度（杆子撑住的步数，越大越好），并存一张学习曲线 PNG。先只看 USE_BASELINE = False 的版本，观察：

  • 曲线会上升，但抖动剧烈——这就是 REINFORCE 高方差的真面目，下一章要治它。
  • 读 policy_gradient_loss()：核心就是 -(logp * G).mean()，对照式 (1.4)。代码里用了 reward-to-go。
  • 把脚本顶部 REWARD_TO_GO = False（改回「整条轨迹同一个总分」），再跑——通常更慢更不稳，验证 1.3 节的「奖励分配」为何重要。

1.4本章小结

  • 策略梯度直接把策略参数化并对期望回报 J(θ) 做梯度上升，天然适配连续动作与随机策略。
  • 得分函数技巧 ∇𝔼[f]=𝔼[f·∇log p] 把梯度从不可微的环境「搬」到可微的策略 log 概率上。
  • 策略梯度定理 (1.3)：梯度 = 回报加权的 ∇log π——好动作点赞、坏动作点踩。
  • REINFORCE + reward-to-go + γ 是最朴素的可用算法，但方差极大，样本利用率低（每批数据只更新一次）。
