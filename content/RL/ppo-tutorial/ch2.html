第 2 章与方差搏斗：基线、优势与 Actor-Critic

REINFORCE 能用，但有个致命弱点——梯度估计的方差极大，训练像喝醉了一样东倒西歪。 本章用三件套把方差摁下去：基线 → 优势函数 → 评论员（critic）。这三样都会原封不动地活在 PPO 里。

2.1问题：高方差从哪来

回忆 REINFORCE 的更新权重是回报 Gt。回报是整条轨迹随机性的累积：动作是采样的、环境转移是随机的、奖励可能有噪声。 一条轨迹运气好得 100 分、运气差得 −50 分，同一个动作可能被忽上忽下地拉扯。用这种「忽大忽小的权重」去推梯度，方向自然抖得厉害。

更要命的是第 1 章 互动 1-A 暴露的现象：当奖励总是正的，每个被采样到的动作都会被「点赞」，只是程度不同。 没被采样到的好动作反而因为别人涨、自己被归一化挤下去。我们真正想要的信号是「这个动作比平均水平好还是差」，而不是「它的绝对分数是多少」。

2.2基线：免费的午餐

办法出奇简单：从回报里减掉一个基线 b(st)：

∇θ J ≈ 𝔼[ Σt ∇θ log πθ(at|st) · ( Gt − b(st) ) ](2.1)

神奇之处在于：无论 b(s) 取什么（只要不依赖动作 a），梯度的期望都不变——基线不引入任何偏差。 一行就能看明白为什么：

∂ 基线为何无偏
𝔼a~π[ ∇θlog πθ(a|s) · b(s) ] = b(s) · Σa πθ(a|s) ∇θlog πθ(a|s) = b(s) · ∇θ Σa πθ(a|s) = b(s) · ∇θ 1 = 0
减掉的那一项，期望恰好是 0。所以期望（=真实梯度）纹丝不动，但方差可以大幅下降——这是真·免费的午餐。

最自然、近乎最优的基线就是状态价值 V(s)：「从这个状态出发，按当前策略平均能拿多少分」。 用它当基线，权重 Gt − V(st) 就变成了「实际拿到的，比预期的好多少」——有正有负，干净利落。来亲手量一量方差到底降了多少。

互动 2-A方差显微镜：基线把梯度估计「收窄」了多少

固定一个策略（不训练），反复用单样本估计某个 logit 的梯度分量 ĝ。下面画出 2000 次估计的分布： 左（红）是不用基线 b=0；右（青）是用基线 b=平均奖励。竖线是各自的样本均值，也叠加了解析真值。

| |
b = 0（无基线）
b = 平均奖励（有基线）

观察：① 两个分布的均值几乎重合，且都落在解析真值上——证明基线不引入偏差； ② 但青色分布窄得多（标准差小很多）——这就是方差下降；③ 勾掉「整体偏正」让奖励有正有负，无基线的劣势会缩小—— 可见基线在「奖励同号」时最救命，正对应第 1 章那个毛病。

2.3优势函数：比平均好多少

把「用 V(s) 当基线」这件事提炼成一个核心概念——优势函数（advantage）：

Aπ(s, a) = Qπ(s, a) − Vπ(s)(2.2)

其中 Q(s,a) 是「在 s 做 a 之后的期望回报」，V(s) 是「在 s 按策略行动的期望回报（对动作取平均）」。 所以 A(s,a) 回答的正是：在状态 s，动作 a 比「照当前策略随便走」好多少。A>0 的动作值得加大概率，A<0 的该减小。 策略梯度于是写成最干净的形式：

∇θ J = 𝔼[ Σt ∇θ log πθ(at|st) · Aπ(st, at) ](2.3)

从第 3 章起，PPO 的目标函数里出现的权重，全都是这个 A。务必把它的直觉焊死在脑子里。

互动 2-B优势 = 高于水平线的部分

某状态有 4 个动作，柱子是它们的 Q 值。青色水平线是 V = Σa π(a)·Q(a)——当前策略的「平均水平」。 柱子高出水平线的部分（绿）是正优势，低于的部分（红）是负优势。拖动「贪婪度」改变策略 π，看水平线 V 怎么移动。

| （β=0 完全均匀；β 越大越偏向高 Q 动作）

观察：① 策略越贪婪（β 大），它越爱选高 Q 动作，平均水平线 V 越往上抬 → 即便是次高的动作，优势也可能变负； ② 优势是相对当前策略的概念，会随策略变化——这正是为什么 PPO 每轮要重新估计优势； ③ 用优势当权重，梯度信号天然「有正有负、以 0 为中心」，方差小、方向准。

2.4评论员登场：Actor-Critic

还有一个问题：式 (2.3) 里的 A(s,a) 我们并不知道，得估出来。最直接的办法是用蒙特卡洛回报： A ≈ Gt − V(st)。但 Gt 本身就是高方差的源头（要等回合结束、积累一路随机性）。

Actor-Critic 的主意是：再训练一个网络来估计 V(s)，叫评论员（critic）， 然后用自举（bootstrap）的方式估优势，比如一步时序差分：

A(st, at) ≈ δt = rt + γV(st+1) − V(st)(2.4)

于是有了两个角色：演员（actor） πθ 负责动作，评论员 Vw 负责打分。 演员朝评论员说好的方向更新，评论员则不断学着把 V 估准。用 δt 替代 Gt−V，方差大降（不必跑完整回合）， 代价是引入了偏差（评论员估不准时会带偏）。这就是著名的 优势演员-评论员（A2C）。

💡 一条贯穿全书的主线：偏差 ↔ 方差
用整条回报 Gt 估优势：无偏，但方差大（蒙特卡洛那一端）。
用一步自举 r+γV(s′)−V(s) 估优势：方差小，但有偏（时序差分那一端）。
能不能在两端之间平滑地调一个旋钮？能——那就是第 5 章的 GAE，PPO 的标配。现在先记住这根轴。
互动 2-C方差下降 = 学得更快：有无基线的学习曲线

回到第 1 章那个「奖励都为正」的 4 臂问题，用完全相同的随机采样，同时训练两个策略： 一个不用基线，一个用「running 平均奖励」当基线。看谁更快把最优动作的概率推上去。

观察：青线（有基线）通常更快、更稳地逼近 1，红线（无基线）爬得慢且抖。 两者用的是同一批样本，差别纯粹来自方差——基线把噪声滤掉了，方向信号更纯净。多点几次「重置→训练」，看不同随机种子下的稳定差异。

⌨ 编程实践 ②基线 / 优势 Actor-Critic

先在 REINFORCE 脚本里打开基线，对比 第 1 章的无基线版本：

cd ~/studyspace/RL/ppo-tutorial/practice
# 编辑 01_reinforce.py，把顶部 USE_BASELINE 改成 True，再跑
python3 01_reinforce.py

然后跑完整的优势 Actor-Critic（演员 + 评论员两个网络）：

python3 02_actor_critic.py

观察与实验：

  • 对比 01（无基线）与 01（有基线）两条学习曲线 PNG：有基线版本抖动明显更小——这就是 2.2 节方差下降在训练上的体现。
  • 02_actor_critic.py 用自举的 GAE 优势，比 REINFORCE 更稳、更省样本，能稳定学到几百分； 但你会发现纯在线 AC 难以又快又稳地冲上满分——这正是后面 PPO（裁剪）要解决的。把 GAE_LAMBDA 设成 0（一步 TD，式 2.4）、0.95、1.0（蒙特卡洛）各跑一次， 观察收敛速度与抖动的变化——这就是在偏差-方差轴上手动滑动，为第 5 章的 GAE 预热。
  • 把评论员学习率 LR_V 调到很小，让评论员「估不准」，看演员如何被带偏——体会自举的偏差代价。

2.5本章小结

  • REINFORCE 的核心病是高方差，根源是用整条轨迹的随机回报当权重。
  • 基线 b(s)：减去它不改变梯度期望（无偏），却能大幅降方差；最佳基线是 V(s)。
  • 优势 A(s,a)=Q−V：「比当前策略的平均好多少」，是 PPO 目标里唯一的权重信号；它随策略变化，需反复估计。
  • Actor-Critic：演员学策略、评论员学 V，用自举的 δ 估优势——以一点偏差换大量方差。偏差↔方差是贯穿到 GAE 的主轴。
